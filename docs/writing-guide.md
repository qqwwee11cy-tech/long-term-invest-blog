# 자동 글쓰기 가이드

자동으로 쓰는 글은 모두 이 가이드를 따릅니다.

## 범위
- 카테고리는 항상 `guide`(장기 투자 정보)입니다. `journal`(내 투자 기록)은 블로그 주인이 직접 씁니다. AI가 주인의 경험이나 매매를 지어내지 않습니다.
- 주제는 `docs/topics.md`의 목록에서 위에서부터 아직 체크되지 않은 것을 고릅니다. 다 썼으면 비슷한 결의 새 주제 5개를 목록에 추가하고 그중 하나를 씁니다.

## 내용 원칙
- 특정 종목·상품의 매수/매도를 권하지 않습니다. 예시로 언급할 때는 "예시"임을 밝힙니다.
- 숫자(세율, 한도, 과거 수익률, 제도 내용)는 웹에서 최신 공식 자료(금융감독원, 국세청, 한국거래소, 운용사 공식 문서 등)로 확인하고, 글 끝 "참고 자료"에 링크를 답니다. 확인할 수 없는 숫자는 쓰지 않습니다.
- 계산 예시는 직접 계산해서 맞는지 확인합니다. 수익률 가정이면 "가정"이라고 적습니다.
- 관련 있으면 사이트의 투자 도구(`/tools/compound/`, `/tools/dca/`, `/tools/portfolio/`)로 연결합니다.

## 형식
- 파일: `src/content/posts/<영문-소문자-하이픈>.md`
- frontmatter: `title`, `description`(검색 결과에 보일 1~2문장, 80자 안팎), `pubDate`(오늘 날짜), `category: guide`, `tags`(2~4개)
- 분량 1,500~2,500자. 짧은 문단, `##` 소제목 3~5개, 필요하면 표.
- 말투: 쉬운 존댓말("~입니다/~해요" 중 하나로 통일), 초보자가 이해할 수 있게.
- 마지막 문단에 핵심 요약 2~3줄.
