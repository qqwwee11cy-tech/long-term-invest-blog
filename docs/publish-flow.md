# 자동 글쓰기와 게시 절차

예약된 자동 글쓰기는 이 절차를 따릅니다. 글은 Claude가 쓰고, **블로그 주인(긍정글귀)이 승인하면 Claude가 게시**합니다. 주인은 메일의 "승인" 버튼(GitHub에서 머지)이나 스레드의 '승인' 한마디로 승인하고, "반려" 버튼으로 다시 쓰게 할 수 있습니다.

1. `docs/writing-guide.md` 전체와 해당 카테고리 절을 읽고, 해당 주제 목록에서 체크되지 않은 첫 주제를 고릅니다 (주간 시장 정리는 목록 없음).
2. 웹 검색으로 사실을 확인하며 글과 SVG 그림을 만듭니다. 주제 목록에서 그 주제를 `[x]`로 바꿉니다.
3. 점검: `docs/writing-guide.md` 맨 위 "블로그 주인의 글쓰기 규칙" 1~8번을 하나씩 확인하고 어긋난 곳을 고칩니다(규칙 9·10). 그다음 글 속 숫자를 출처와 다시 대조, 그래프 숫자와 본문 일치, 매수/매도 권유·목표주가·전망 표현 없음, 문장 베끼기 없음, frontmatter 확인, `npm install && npm run build` 통과, 가능하면 Playwright(executablePath `/opt/pw-browsers/chromium`)로 390px 너비 스크린샷 확인.
4. 새 브랜치 `post/<파일명>`으로 커밋·푸시하고 main 대상 PR을 엽니다. `subscribe_pr_activity`로 PR을 지켜봅니다. 미리보기 주소는 직접 만들지 말고, PR에 vercel[bot]이 다는 댓글의 Preview 주소를 그대로 씁니다(브랜치 이름이 길면 주소가 잘려 바뀝니다). 그 뒤에 `/posts/<파일명>/`을 붙입니다. 브랜치 이름은 짧게(`post/<짧은이름>`) 짓습니다.
5. 승인 요청
   - 이 스레드에 reply: 제목, 요약 2~3문장, 미리보기 링크, 그리고 "괜찮으면 여기에 '승인'이라고 보내주세요. 제가 바로 게시할게요. 고칠 점은 말로 적어주시면 반영할게요."
   - Gmail 도구(`mcp__Gmail__send_message`, ToolSearch로 불러오기)가 있으면 `qqwwee11.cy@gmail.com`으로 메일. 제목 `[천천히 부자되기] 새 글 승인 요청: 「제목」`. htmlBody는 흰 배경, 강조색 #1f7a4d, 최대 너비 520px 카드: 제목, 요약, "미리보기" 링크, 그리고 버튼 두 개를 나란히 둡니다.
     - 초록 버튼 **승인** → PR 주소 `https://github.com/qqwwee11cy-tech/long-term-invest-blog/pull/<번호>`. 안내: "열린 화면 아래의 초록 'Squash and merge' → 'Confirm'을 누르면 바로 게시돼요."
     - 회색 버튼 **반려** → `https://github.com/qqwwee11cy-tech/long-term-invest-blog/pull/<번호>#new_comment_field`. 안내: "'반려'와 고칠 점을 댓글로 남기면 다시 써서 새 미리보기를 보내드려요."
     - 마지막에 작은 글씨: "프로젝트 스레드에 '승인' 또는 '반려: 이유'라고 보내도 돼요."
     body에는 같은 내용을 일반 텍스트로. 메일을 못 보냈으면 스레드에 한 줄 적습니다.
   - 아직 게시되지 않은 이전 post/ PR이 있으면 "승인 대기 중인 글 N편"을 덧붙입니다.
6. 주인의 응답에 따라 처리합니다. 주인의 승인 없이는 머지하지 않습니다.
   - **승인** (스레드에서 '승인'): PR을 squash 머지해 게시하고, 1~2분 뒤 게시된 글 링크를 알려줍니다.
   - **주인이 GitHub에서 직접 머지** (PR merged 이벤트): 게시된 것이니 스레드에 게시된 글 링크를 한 줄로 알립니다.
   - **반려** (PR 댓글이나 스레드 메시지에 '반려'): 적힌 이유를 반영해 같은 브랜치에서 글을 다시 씁니다. 이유가 없으면 주제는 유지하고 구성·설명·그림을 새로 다듬습니다. 3단계 점검을 다시 하고 푸시한 뒤, PR에 무엇을 바꿨는지 짧은 댓글을 달고 5단계(스레드 reply + 메일)를 다시 합니다.
   - 게시하지 말라고 하면 PR을 닫고 주제 목록의 `[x]`를 되돌립니다.
