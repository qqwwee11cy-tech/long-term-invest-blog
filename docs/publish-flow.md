# 자동 글쓰기와 게시 절차

예약된 자동 글쓰기는 이 절차를 따릅니다. 글은 Claude가 쓰고, **블로그 주인(긍정글귀)이 메일의 "승인" 버튼을 누르면 바로 게시**됩니다. 미리보기는 블로그 주소(`/preview/<파일명>/`)에서 열립니다.

## 동작 방식
- 초안은 `draft: true`로 main에 올립니다. 초안은 글 목록·RSS·사이트맵에 나오지 않고, `/preview/<파일명>/`에서만 보입니다(검색엔진 noindex).
- 글마다 승인 키를 만들고, 키의 해시만 frontmatter `approveHash`에 저장합니다. 키 자체는 메일에만 들어갑니다(저장소가 공개라서).
- 승인 버튼(`/api/approve`)은 확인 화면 → "지금 올리기"를 누르면 GitHub API로 `draft: false`, `pubDate` 오늘(한국 시간), `approveHash` 삭제를 main에 커밋합니다. Vercel이 1~2분 안에 배포합니다.
- 반려 버튼(`/api/reject`)은 고칠 점을 받아 GitHub 이슈 `반려: <파일명>`을 만듭니다.
- 두 버튼은 Vercel 환경 변수 `GITHUB_TOKEN`(이 저장소만, Contents·Issues 읽기/쓰기)이 있어야 동작합니다.

## 절차
0. **반려 먼저 처리**: 열린 이슈 중 제목이 `반려: `로 시작하는 것이 있으면 새 글보다 먼저 처리합니다. 이슈의 고칠 점을 반영해 그 초안을 다시 쓰고(이유가 없으면 주제는 유지하고 구성·설명·그림을 새로 다듬기), 아래 3~5단계를 거친 뒤 이슈에 무엇을 바꿨는지 댓글을 달고 닫습니다.
1. `docs/writing-guide.md` 전체(특히 맨 위 "블로그 주인의 글쓰기 규칙")와 해당 카테고리 절을 읽고, 해당 주제 목록에서 체크되지 않은 첫 주제를 고릅니다 (주간 시장 정리는 목록 없음). 주제 목록에서 그 주제를 `[x]`로 바꿉니다.
2. 웹 검색으로 사실을 확인하며 글과 SVG 그림을 만듭니다. frontmatter에 `draft: true`를 넣습니다.
3. 점검: "블로그 주인의 글쓰기 규칙" 1~8번을 하나씩 확인하고 어긋난 곳을 고칩니다(규칙 9·10). 글 속 숫자를 출처와 다시 대조, 그래프 숫자와 본문 일치, 매수/매도 권유·목표주가·전망 표현 없음, 문장 베끼기 없음, `npm install && npm run build` 통과, 가능하면 Playwright(executablePath `/opt/pw-browsers/chromium`)로 390px 너비 스크린샷 확인.
4. `node scripts/approval-link.mjs <파일명>`을 실행합니다. 새 승인 키를 만들어 해시를 frontmatter에 넣고, 미리보기·승인·반려 주소를 출력합니다(다시 쓸 때마다 새로 실행하면 이전 메일의 버튼은 더는 동작하지 않습니다). main에 바로 커밋·푸시합니다. 1~2분 뒤 배포됩니다.
5. 승인 요청
   - 프로젝트 스레드에 reply: 제목, 요약 2~3문장, 미리보기 링크, "메일의 승인 버튼을 누르거나 여기에 '승인'이라고 보내면 바로 게시돼요."
   - Gmail 도구(`mcp__Gmail__send_message`, ToolSearch로 불러오기)로 `qqwwee11.cy@gmail.com`에 메일. 제목 `[천천히 부자되기] 새 글 승인 요청: 「제목」`. htmlBody는 흰 배경, 강조색 #1f7a4d, 최대 너비 520px 카드: 제목, 요약, "미리보기" 링크(4단계의 preview 주소), 그리고 버튼 두 개를 나란히 둡니다.
     - 초록 버튼 **승인** → 4단계의 approve 주소. 안내: "누르고 '지금 올리기'를 한 번 더 누르면 바로 게시돼요."
     - 회색 버튼 **반려** → 4단계의 reject 주소. 안내: "고칠 점을 적으면 다시 써서 새 메일을 보내드려요."
     - 마지막에 작은 글씨: "프로젝트 스레드에 '승인' 또는 '반려: 이유'라고 보내도 돼요."
     body에는 같은 내용을 일반 텍스트로. 메일을 못 보냈으면 스레드에 한 줄 적습니다.
   - 아직 게시되지 않은 다른 초안이 있으면 "승인 대기 중인 글 N편"을 덧붙입니다.
6. 스레드에서 답이 오면
   - **승인**: 승인 버튼과 같은 변경(`draft: false`, `pubDate` 오늘, `approveHash` 줄 삭제)을 main에 커밋·푸시하고, 1~2분 뒤 게시된 글 링크를 알려줍니다.
   - **반려**: 0단계처럼 다시 씁니다.
   - 게시하지 말라고 하면 초안 파일과 그림을 지우고 주제 목록의 `[x]`를 되돌립니다.
   - 주인의 승인 없이는 `draft: false`로 바꾸지 않습니다.
